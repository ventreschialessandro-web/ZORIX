# Ether-Soul-AI-Companion Ether Soul is a full-stack AI chatbot web application that acts as a spiritual companion — built with a secure serverless architecture using Netlify Functions, Firebase Authentication, and multiple AI/knowledge APIs. Tech Stack LayerTechnologyFrontendHTML5, CSS3, JavaScript (ES6+), Tailwind CSSBackendNetlify Serverless FunctionsAuthFirebase AuthenticationAI ModelsGoogle Gemini AI (gemini-2.5-flash) / Groq (Llama 3.3 70B)DeploymentNetlify (CI/CD with GitHub)Languages SupportedEnglish, Hindi, MarathiAPIs Integrated6 total Features Multi-modal AI chat — Routes queries to Gemini AI or factual APIs (Wikipedia, Google Books, Archive.org) based on context Firebase Authentication — Supports Google Sign-In (OAuth 2.0), Email/Password, and Guest Mode Multi-language support — Automatically detects and responds in English, Hindi, or Marathi using Unicode range detection Rate limiting — Queue-based system enforces a 1-second interval between requests; handles 429 errors gracefully with user-friendly messages Emotion tracking — Detects emotional keywords and renders contextual suggestion chips after each AI response Typing animation — Character-by-character response rendering with a 20ms async loop Secure API proxy — API keys are stored as Netlify environment variables, never exposed to the browser Architecture The app follows a client-server architecture with a secure serverless backend: User (Browser) │ ├── Factual query? ──► Wikipedia / Google Books / Archive.org (direct) │ └── Spiritual/personal query? │ ▼ POST /.netlify/functions/chat │ ▼ Netlify Serverless Function (reads GEMINI_API_KEY from env) │ ▼ Google Gemini AI API │ ▼ Response → Browser → Typing animation The API key is never sent to the browser. It lives only on Netlify's servers as an environment variable. Deployment The project uses Netlify's built-in CI/CD pipeline: Push changes to GitHub Netlify detects the push via webhook and builds automatically npm install installs dependencies esbuild bundles the serverless function Site goes live on Netlify's global CDN To deploy manually: bashgit add . git commit -m "your message" git push Security API keys are stored as Netlify environment variables — never in source code The serverless function acts as a proxy, adding the key server-side .gitignore prevents .env from being committed to GitHub CORS headers are set in chat.js (Access-Control-Allow-Origin: *) Incoming request payloads are validated before forwarding to Gemini To verify: Open the live site → F12 → Sources tab → Search for AIza (Google key prefix) — it should not appear anywhere in the browser code.
